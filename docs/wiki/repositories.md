# 공개 저장소 목록과 문서 작성 상태

2026-10-27에 [공개 저장소 목록](https://github.com/kdkrkwhr?tab=repositories)에서 `kdkrkwhr` 계정의 공개 저장소 28개를 확인했다. **목록 확인과 코드 분석은 다르다.** 현재 상세 문서는 [노트버디](notebuddy.md), [옥션스팟 API](auction-spot.md), [AGENT HUB](agent-hub.md) 세 개다. 아래의 다른 이름은 조사 후보일 뿐, 기술·역할·성과를 검증했다는 뜻이 아니다. 공개 저장소 중 fork는 세 개이고, 나머지 25개가 non-fork다. non-fork라는 표시도 단독 저작을 뜻하지 않는다.

## 상세 문서 작성 완료 · 3

- `notebook-pets` → [노트버디](notebuddy.md): README와 Python·JavaScript 파일을 고정 커밋에서 대조했다.
- `auction-spot-api` → [옥션스팟 API](auction-spot.md): README와 Java 이미지 저장 경로를 고정 커밋에서 대조했다.
- `agent-hub` → [AGENT HUB](agent-hub.md): README와 Python CLI·서버·작업 엔진·사본 코드를 고정 커밋에서 정적으로 대조했다.

## 후속 조사 후보 · 22

다음 non-fork 저장소에는 아직 이 위키의 상세 분석 문서가 없다. 코드와 README를 확인한 뒤 프로젝트, 연습·템플릿, 운영 자료 등을 구분한다.

- `auction-spot-front`, `hermes-env`, `hermes-agent-area`, `hermes-team-hub`, `agent-drift-guard`
- `engineering-standards`, `attendance-pwa`, `msa-architecture`, `spring-boot`, `spring-react-template`, `airport-parking`
- `flask-leaflet`, `flutter-profile`, `dl-object-tracking`, `dl-object-detecting`, `dl-data-training`, `dl-tesseract`
- `algorithms`, `kdkrkwhr.github.com`, `resume`, `kdkrkwhr`, `kdk-knowledge`

`engineering-standards`는 [참고 기준](standards.md)으로 연결했지만 프로젝트 상세 분석 대상으로 완료 처리하지 않는다. `agent-drift-guard`의 공개 README는 중단된 상태와 대체 경로를 설명하므로 새 분석 때 현재 운영 프로젝트처럼 다루지 않는다. `resume`, 프로필, 웹사이트 자료를 살필 때 공개돼 있다는 이유만으로 연락처 등 불필요한 개인정보를 이 위키에 다시 싣지 않는다.

## Fork · 3

fork 관계는 GitHub의 저장소 메타데이터에서 확인한 분류다. 이 목록만으로 수정 기여나 본인 프로젝트라고 쓰지 않는다. 실제 기여 문서를 만들려면 커밋·PR 등 별도 근거가 필요하다.

새 문서를 작성하는 순서와 공개 검증은 [문서 갱신 절차](maintenance.md)를 따른다.
