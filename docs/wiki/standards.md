# 개발 기준 자료의 위치

[Engineering Standards README](https://github.com/kdkrkwhr/engineering-standards/blob/e1c019df54898e928f871602b76fa463d3ec7930/README.md)는 별도 공개 기준 저장소의 진입점이다. 이 위키는 [노트버디](notebuddy.md), [옥션스팟 API](auction-spot.md) 같은 프로젝트에서 확인한 문제·구현·기술·배움을 중심에 둔다. 기준은 연결할 수 있는 자료 중 하나다.

현재 두 사례가 해당 기준을 실제 적용했다는 문서나 커밋 근거는 등록되지 않았다. 프로젝트의 결정 기록이 공개되면 어떤 기준을 언제 어떻게 사용했는지 별도 관계로 연결한다.
