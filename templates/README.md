# 기록 입력 템플릿

이 저장소는 **공개** 저장소입니다. 아래 항목을 채운 뒤 바로 커밋하지 말고, 각 문장과 출처의 공개 가능 여부를 먼저 확인하세요. 원본에 없는 역할·성과·선택 이유는 추측하지 않습니다. 비공개 자료나 개인정보를 여기에 임시로도 넣지 않습니다.

공통 필드: `id`, `제목`, `사실 / 해석 / 배움 구분`, `공개 상태(public 또는 hold)`, `출처 URL`, `고정 커밋 SHA 또는 문서 버전`, `확인한 날짜`, `연결할 항목 ID`. `hold`는 공개 저장소에 기록할 내용이 아니라 보류 상태를 뜻합니다.

원본 프로젝트의 위키는 필요하지 않습니다. 공개 README·코드·설계 문서의 구체적 파일을 먼저 읽고, 확인한 사실마다 그 파일과 커밋을 붙입니다. 선택 이유나 회고가 원본에 없으면 빈 칸으로 둡니다.
