    질문 / 01

    같은 행동 규칙을 웹과 Anna가 어떻게 사용하나?

    공개 코드의 game_api.py는 상태와 명령을 받아 다음 상태·결과·이벤트를 계산하는 transition을 정의합니다. 브라우저 Worker는 Pyodide에서 이 Python 함수를 호출하고, Anna Worker도 같은 함수를 호출합니다. 따라서 이 사례의 확인된 연결은 두 실행 경로가 공통 전이 함수에 도달한다는 것입니다. 전이 함수 ↗ · 웹 Worker ↗ · Anna Worker ↗

    사용 경험 / 02

    성장은 자동 확정이 아니라 선택으로 이어진다

    공개 README에 따르면 레벨과 활동 조건을 채운 뒤 사용자가 진화 버튼을 누르고 세 방향 중 하나를 고릅니다. AI는 방향을 제안하고, 선택한 모습의 그림 생성은 별도 요청입니다. 이 설명은 공개된 제품 흐름이며, 그 결정을 개인이 왜 내렸는지는 아직 기록하지 않았습니다. 기능 설명 원본 ↗

    확인한 기술

    Python 게임 전이 함수

    Pyodide 브라우저에서 Python 실행

    Anna Worker 같은 전이 함수 호출

    아직 비어 있는 기록

    개인 담당 범위, 성과, 이 구조를 선택한 이유와 회고는 공개 근거가 확인되면 추가합니다.

    질문 / 01

    이미지 업로드의 실제 저장 위치는?

    README는 설계 문서의 S3와 달리 현재 API가 서버 로컬 디스크를 사용한다고 명시합니다. LocalUploadController가 multipart 파일을 받고, LocalImageStorageService.java가 허용 형식·크기를 검사한 뒤 파일을 저장하며, LocalFileWebConfig가 파일 URL 경로를 연결합니다. 이는 현재 공개 코드에서 관찰한 구현입니다. 전환 배경이나 운영 성과는 확인되지 않았습니다. 업로드 진입점 ↗ · 저장 구현 ↗ · 파일 제공 설정 ↗

    기술 / 02

    공개된 기술과 아직 모르는 이유를 구분합니다

    README는 Java 21, Spring Boot 3.x, MySQL, Redis, WebSocket(STOMP)를 API 구성 요소로 열거합니다. 이것은 사용 사실의 근거입니다. 각 기술을 선택한 이유와 개인이 맡은 범위는 README와 위 코드만으로 확정할 수 없습니다. 기술 구성 원본 ↗
