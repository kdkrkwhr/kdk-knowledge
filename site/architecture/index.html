관계는 공개 저장소의 README와 위키·기준 문서를 근거로 사람이 등록했습니다. 관계 JSON에서 출처 URL, 전체 커밋 SHA, 관계의 출처 종류를 확인할 수 있습니다. 연결 수가 적다는 사실은 프로젝트 경험이 적다는 뜻이 아니라 아직 이 허브에 확인된 자료가 적다는 뜻입니다.

노트버디의 기존 구조 지도에는 별도로 실행한 Graphify 코드 분석이 있습니다. 그것을 이 허브의 자동 분석 결과로 합치지 않았습니다. 향후 Graphify를 사용할 때는 실행 버전, 입력 파일 범위, 분석 커밋, 외부 전송 여부를 기록하고 편집 관계와 다른 층으로 표시합니다.
