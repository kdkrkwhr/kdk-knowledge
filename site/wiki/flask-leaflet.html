    분석 기준: cccfdf98ef0d6205ac007bcfcb338decb9ec7c50. 이 문서는 공개 원본 파일을 정적으로 읽어 작성했다. 해당 프로젝트의 설치·실행·테스트를 수행하거나 개인 담당 범위·성과를 확인한 것은 아니다.

    냉정한 기술 평가

    평가일: 2026-10-28 · 근거 커밋: cccfdf98ef0d6205ac007bcfcb338decb9ec7c50. 공개 소스의 정적 평가이며 실제 운영 결과나 개인의 기여 범위를 확정하지 않는다.

    • 구조·설계 — 양호 Flask 라우트가 지도 예제별 HTML을 제공하고 CCTV 지도 스크립트가 위치·레이어 표시를 담당한다. app.py 5–23행 cctvMap.js 47–111행
    • 구현 품질 — 보완 필요 지도 스크립트는 일부 타일을 HTTP로 요청하고 외부 지도 서비스 키를 클라이언트 코드에 직접 둔다. HTTPS 페이지에서는 지도 자산이 막히거나 키 사용 범위를 통제하기 어려울 수 있다. 키 값은 이 평가에 옮기지 않는다. cctvMap.js 7–29행
    • 운영 준비 — 위험 직접 실행 경로가 debug 모드로 모든 네트워크 인터페이스에 바인딩한다. 공개 환경에서 그 방식으로 시작하면 개발용 디버거가 노출될 수 있다. 실제 공개 실행 여부는 확인하지 않았다. app.py 25–26행
    • 유지보수 — 보완 필요 HTML의 인라인 이벤트와 전역 지도 상태가 결합돼 화면을 확장할 때 이벤트 흐름을 추적하기 어렵다. cctv_map.html 21–52행 cctvMap.js 1–5행

    좋은 점: 각 지도 예제의 입구가 작고 CCTV 레이어 조작 흐름이 보인다. 개선 우선순위: P1 — 외부 노출용 실행 설정에서 debug를 끄고 바인딩을 제한한다. P2 — 타일 HTTPS와 지도 키 제한·교체 정책을 정한다.
