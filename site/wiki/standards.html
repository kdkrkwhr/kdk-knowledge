    Engineering Standards: 선택형 개발 기준과 그 적용 경계

    이 저장소는 프로젝트를 시작하거나 변경할 때 사용할 선택형 기준을 제공한다. 개인 지식 허브의 전체 목적이 아니라 프로젝트에서 필요할 때 참조할 한 영역이다. README는 공통 원칙·명명·구조 선택, 언어별 프로필, 프레임워크별 프로필을 구분하고, 특정 언어나 아키텍처를 모든 프로젝트에 강제하지 않는다고 밝힌다. 이 문서를 작성했다는 사실만으로 다른 프로젝트에 적용됐다는 뜻도 아니다. 기준 저장소 README

    사람이 선택하는 범위

    README의 적용 흐름은 기준 저장소 커밋을 고정한 뒤 필요한 문서를 소비 프로젝트에 배치하고, 프로젝트의 기존 지침과 충돌을 검토하는 것이다. 예를 들어 profiles/languages/python.md는 이름·모듈·테스트 파일 규칙을 다루되 특정 프레임워크나 런타임 버전을 필수로 하지 않는다. profiles/frameworks/spring-boot.md는 새 프로젝트의 네 계층 기본안을 제시하지만 기존 기능별 구조를 먼저 존중한다. 언어 프로필과 프레임워크 프로필은 각각 선택한다. 적용 안내 · Python 프로필 · Spring Boot 프로필
