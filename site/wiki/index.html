    프로젝트에서 시작하는 위키

    이곳은 김동기의 공개 GitHub 저장소에서 확인한 내용을 이 저장소의 Markdown 문서로 정리한 중앙 위키다. 원본 저장소에 별도 위키가 없어도 README·코드·설계 문서만으로 기록할 수 있다. 문서 속 원본 링크는 확인한 커밋에 고정했다.

    지금 읽을 수 있는 프로젝트

    • 노트버디: Python 상태 전이 함수가 웹 Pyodide와 Anna Worker에 연결되는 흐름. 게임 저장과 진화 조건도 공개 코드를 따라 설명한다.
    • 옥션스팟 API: README의 서비스 구성을 출발점으로, 실제 이미지 업로드·로컬 저장·파일 제공 경로를 Java 코드에서 확인한다. 원본 프로젝트 위키 없이 작성한 사례다.
    • AGENT HUB: 로컬 CLI 호출, SQLite 작업 큐, 토론·검토 사본을 공개 코드의 경계에 따라 읽는다.

    다른 방향으로 읽기

    • Python 실행 경계, 로컬 이미지 저장, 로컬 작업 큐는 프로젝트의 기술 사용 사실을 연결한다.
    • 개발 기준 참고는 별도 기준 저장소의 위치를 설명한다. 사례 프로젝트에 적용됐다는 근거는 아직 없다.
    • 공개 저장소 목록과 작성 상태는 분석 후보와 완료한 문서를 구분한다.
    • 문서 갱신 절차는 공개 근거를 등록하고 문장을 대조하는 방법이다.

    프로젝트를 소유하거나 공개했다는 사실만으로 개인 담당 범위·성과·선택 이유는 알 수 없다. 이 부분은 공개 가능한 기록이 생길 때까지 비워 둔다. 관계 지도는 이 문서의 근거를 사람이 연결한 결과이며, Graphify 자동 추출 결과가 아니다.
