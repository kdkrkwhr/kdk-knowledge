    평가일: 2026-10-28 · 근거 커밋: a6b6af0142a3d57ebeac89c38c89d9dadd614c59. 공개 소스의 정적 평가이며 실제 운영 결과나 개인의 기여 범위를 확정하지 않는다.

    • 구조·설계 — 양호 단일 학습 스크립트에서 이미지 전처리·CNN 구성·학습·저장을 순서대로 볼 수 있어 실험 기록 목적에는 맞다. train_car.py 18–83행

    • 운영 준비 — 미확인 입력 디렉터리와 출력 파일이 상대 경로로 고정된 일회성 학습 스크립트다. 서비스 운영 준비도는 적용 대상이 아니다. train_car.py 63–83행
    • 유지보수 — 보완 필요 데이터 위치·epoch·모델 크기가 코드 안에 있어 다른 데이터셋을 재현하려면 원본 스크립트를 편집해야 한다. train_car.py 19–22·55–77행

    저장소 범위

    이 저장소의 공개 파일은 train_car.py 한 개다. README나 학습 데이터·의존성 잠금 파일은 없다. 따라서 파일 이름 이상의 제품 목적이나 데이터 출처를 추정하지 않는다. 원본: `train_car.py`

    스크립트가 하는 일

    코드는 다섯 Conv2D·MaxPool·Dropout 묶음 뒤 Flatten·Dense와 3분류 softmax를 만든다. ImageDataGenerator가 ./input/data/train_data와 test_data 폴더에서 128×128 이미지를 읽고 학습·검증에 공급한다. 완료되면 모델 파일과 JSON을 저장하고 정확도 그래프를 그리려 한다. 원본: `train_car.py`

    정적 검토에서 보이는 제약

    파일에는 60 epoch 학습 뒤 그래프용 epoch 열을 30개만 만드는 부분이 있다. 데이터 폴더와 런타임 버전이 없으므로 실행 성공이나 결과 정확도는 확인할 수 없다. 모델·그래프 출력 경로의 사용 가능 여부도 실행하지 않았다. 원본: `train_car.py`
