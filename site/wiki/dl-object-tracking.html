    자료와 출처

    README는 Python 3.7, TensorFlow 1.13, OpenCV, SSD를 실험 환경으로 소개하고 외부 Object Detection·차량 계수 참고 자료를 밝힌다. custom_vehicle_training 아래에는 이미지·XML 라벨·CSV와 TensorFlow Object Detection 소스 트리가 함께 있다. 저장소에 코드가 존재한다는 것만으로 모든 검출기 구현을 개인 창작물이라 말할 수 없다. 원본: `README.md` 원본: `custom_vehicle_training/README.md`

    학습 데이터 변환 경로

    generate_tfrecord.py는 CSV 라벨을 파일명별로 묶고 이미지를 읽어 좌표를 크기로 정규화한다. motorcycle·car·bus·truck을 번호로 매핑한 다음 TensorFlow Example을 직렬화해 TFRecord로 기록한다. 이 문서에서 실제 이미지나 학습 모델을 돌리지 않았다. 원본: `custom_vehicle_training/generate_tfrecord.py`
