    냉정한 기술 평가

    평가일: 2026-10-28 · 근거 커밋: d61bd752deb16ef19df40f420a038d81a21519ca. 공개 소스의 정적 평가이며 실제 운영 결과나 개인의 기여 범위를 확정하지 않는다.

    • 구조·설계 — 양호 흐림·이진화·윤곽 검출·문자 인식의 실험 단계를 함수로 나눴다. main.py 9–43·93–125행
    • 구현 품질 — 보완 필요 이미지 읽기 결과가 없는 경우를 확인하기 전에 전처리를 시작한다. 입력 파일이 없거나 읽을 수 없으면 실패 원인이 흐려진다. main.py 120–125행
    • 운영 준비 — 미확인 한 장의 고정된 로컬 이미지를 GUI로 보여 주는 실험이며 배치·서비스 운영 대상으로 작성된 증거는 없다. main.py 117–126행
    • 유지보수 — 보완 필요 윤곽 함수의 반환값 세 개를 고정으로 받으므로 OpenCV API 형태에 결합돼 있다. 의존성 버전과 입력 예제를 기록하면 재현성이 좋아진다. main.py 20–24·37–44행

    좋은 점: 전처리와 인식의 단계가 명시적이다. 개선 우선순위: P2 — 입력 파일 확인과 윤곽 반환형 처리 경계를 두면 환경·입력 차이에서 원인을 빠르게 알 수 있다.

    이미지 처리 흐름

    main.py는 고정된 테스트 이미지를 읽고 GaussianBlur, 회색 변환, Canny·임계값, morphology로 후보 윤곽선을 만든다. 사각형의 회전·면적·종횡비를 검사한 뒤 후보 영역을 잘라 Tesseract로 문자를 읽고 화면에 덧쓴다. 원본: `main.py`

    README는 OpenCV·Tesseract 버전과 샘플 이미지를 안내한다. 테스트 이미지 폴더가 있지만 이 정적 분석에서 OCR 결과나 인식률을 재현하지 않았다. 원본: `README.md` 원본: `main.py`

    호환성 경계

    코드는 cv2.findContours의 반환값 세 개를 받는 형태라 OpenCV 버전에 민감하다. README의 환경을 벗어난 최신 설치에서 동일하게 동작한다고 보장하지 않는다. 원본: `main.py` 원본: `README.md`
