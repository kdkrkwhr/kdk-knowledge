    공개 저장소 목록과 문서 작성 상태

    2026-10-27에 공개 저장소 목록에서 kdkrkwhr 계정의 공개 저장소 28개를 확인했다. 25개 non-fork와 3개 fork 모두 고정 커밋에서 실제 소스·설정 중 핵심 파일을 읽고, README가 있는 경우 안내와 대조해 문서를 작성했다. 정적 분석은 실행 검증이나 개인 기여 검증이 아니다. 특히 큰 기술 모음과 upstream fork는 문서에 적힌 파일 범위만 조사했다. non-fork도 단독 저작을 뜻하지 않는다.

    fork 관계는 GitHub 저장소 메타데이터에서 확인했다. 기본 브랜치 비교만으로 다른 브랜치나 외부 PR 기여까지 배제할 수 없다. upstream README의 기능·성과를 fork 계정 소유자의 성과로 옮기지 않았다.
