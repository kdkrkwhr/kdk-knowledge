    Python 실행 경계: 공통 규칙과 서로 다른 호출자

    노트버디 사례에서 확인한 Python의 역할은 화면 기술 전체가 아니라 게임 상태 전이 계산이다. engine/game_api.py의 transition은 상태·명령·ExecutionContext를 받아 결과와 다음 상태를 돌려준다. 실행 문맥에는 시각·난수원·ID 생성기 등 계산에 필요한 외부 입력이 담긴다. 전이 코드 · 실행 포트

    두 호출 경로

    브라우저의 JavaScript Worker는 Pyodide로 Python 코어를 적재하고 메시지를 transition에 전달한다. Anna Worker도 허용 명령을 확인한 뒤 같은 전이 함수로 들어간다. 두 Worker의 입력·출력 처리가 같다는 주장이 아니라, 게임 규칙의 진입점이 같다는 관찰이다. 브라우저 Worker · Anna Worker

    웹의 저장은 전이 계산과 별도로 web/store.js가 IndexedDB에 수행한다. 코드에는 리비전을 비교한 갱신 경로가 있다. 이 저장 방식을 Anna의 영속화 방식으로 일반화하지 않는다. 브라우저 저장
