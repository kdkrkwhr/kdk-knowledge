    노트버디: 한 친구의 규칙을 여러 화면에서 실행하기

    그림·사진에서 시작한 친구의 행동을 공통 Python 규칙으로 계산하는 공개 프로젝트

    냉정한 기술 평가해결 대상과 사용자 흐름실제 구조: 상태 전이와 실행 환경주요 실행·데이터 흐름확인한 기술과 연결 문서확인 범위와 남은 질문관련 개념근거 문서

    노트버디는 그림이나 사진에서 친구를 만들고, 돌봄·대화·산책·모험을 이어 가는 공개 프로젝트다. 이 문서는 사용 안내를 다시 나열하기보다 화면에서 선택한 행동이 어떤 코드에서 판정되고 저장되는지를 따라간다. 제품 범위는 프로젝트 README를 기준으로 읽었다. 이 문서가 기술 선택의 개인적 동기나 담당 범위를 증명하지는 않는다.

    해결 대상과 사용자 흐름

    공개 README의 사용자 흐름은 그림·사진 또는 랜덤 선택으로 친구를 만나는 데서 시작한다. 이후 먹이, 놀이, 훈련, 수면, 대화로 상태와 경험을 쌓고 산책·던전을 탐색한다. 진화는 레벨만 올랐다고 즉시 일어나지 않는다. 활동 조건을 채운 뒤 사용자가 시점을 정하고 세 방향 중 하나를 고른다. AI는 방향 설명과 외형 제안을 보탤 수 있지만, 어떤 방향을 선택할지는 사용자에게 남는다. 기능 설명 원본

    이 흐름에는 게임 규칙, 플랫폼별 화면과 저장, AI가 만드는 표현이 섞여 있다. 공개 코드에서 확인되는 경계를 분리해 읽어야 한다. 세부 실행 환경은 Python 실행 경계에 모았다.

    실제 구조: 상태 전이와 실행 환경

    공통 진입점인 engine/game_api.py의 transition은 기존 상태, 명령, 실행 문맥을 받아 결과와 다음 상태, 변경 여부, 이벤트를 담은 TransitionResult를 돌려준다. 이 함수 안에서 명령 형식과 접근 범위를 검사한 뒤 엔진 명령을 분배한다. 파일 저장은 이 함수가 직접 수행하지 않는다. 별도의 GameApplication은 저장소에서 상태를 읽고, 전이 결과가 바뀌었을 때 리비전을 확인하며 교체한다. 전이 함수와 저장 경계

    ExecutionContext에는 규칙 데이터, 템플릿, 현재 시각, 난수원, ID 생성기가 들어간다. 즉 전이 계산에 필요한 외부 입력을 호출자가 건네는 형태다. 저장소 계약은 load와 compare_and_set으로 드러난다. 이것은 코드에서 관찰한 의존 경계이며, 그렇게 설계한 개인적 이유는 공개 근거만으로 확정할 수 없다. 실행 문맥과 저장소 계약

    주요 실행·데이터 흐름

    1. 웹 Worker는 Pyodide를 준비하고 Python 코어 파일과 규칙 데이터를 브라우저 환경에 적재한다. 메시지를 받으면 transition을 호출하고 결과·상태·화면용 뷰를 다시 JavaScript 쪽으로 보낸다. 웹 Worker 원본
    2. Anna Worker는 허용 명령을 확인하고 게임 코어의 transition을 호출한다. 반환값에는 결과, 상태, 변경 여부와 뷰가 들어간다. 상위 GameService.invoke는 APS에 저장된 값·ETag를 읽고 요청 영수증과 게임 상태를 함께 구성해 조건부로 쓴다. 기존 행은 ETag 충돌을 재시도하지만 최초 생성은 쓰기 전 재조회만 하며 원자적 생성 조건을 보장하지 않는다. GameApplication의 일반 저장소 계약을 Anna 구현에 그대로 적용했다고 읽으면 안 된다. Anna Worker · Anna 저장 오케스트레이션 128–183행 · 공통 계약 81–111행
    3. 웹 저장 모듈은 IndexedDB의 saves 저장소에서 플레이어 상태를 읽고 리비전을 비교해 갱신한다. 플레이어와 그림 데이터를 별도 키로 관리하며, 교체할 때는 같은 트랜잭션을 사용한다. 이 사실은 웹 구현에 한정된다. 웹 저장 코드

    진화 코드에서는 다음 단계의 레벨·돌봄·훈련·산책 등 조건을 계산하고, 진행 중인 선택을 먼저 끝내야 하는 상황을 구분한다. 후보 방향을 예약·선택하는 흐름이 있으며, AI 설명은 게임 조건 자체를 결정하는 값과 분리돼 있다. 여기서는 코드의 경계를 설명할 뿐 실제 배포판의 모든 화면 상태를 재검증했다고 주장하지 않는다. 진화 규칙 원본
